Features

Built for privacy. Optimised for speed.

Everything runs on your machine. No subscriptions, no cloud, no surprises.

🔒

Privacy First

All audio processing, transcription, and text improvement happen entirely on your local machine. Zero telemetry, zero cloud calls.

🌐

Fully Offline

No internet connection required. Whisper and Ollama run locally, so Speak-Type works on flights, in coffee shops, anywhere.

🪶

Lightweight When Idle

The menu-bar process uses less than 1% CPU and ~100 MB RAM when not actively recording. It stays out of your way.

⚡

Fast Turnaround

From speaking to clipboard-ready text in 1–4 seconds. Whisper transcribes in under 1.5 s, the local LLM polishes in under 2 s.

🍎

Native macOS Feel

Lives in your menu bar via rumps. Start recording, stop, and paste — three clicks, no windows to manage.

⚙️

Fully Configurable

Swap Whisper model sizes, change the Ollama model, tune silence detection, or customise the improvement prompt via a single config.yaml.

How it works

From voice to clipboard in seconds

A simple, auditable pipeline — every step happens on your machine.

1

Click "Start Recording" from the menu bar

The menu-bar icon changes to ⏺️ and begins capturing audio from your microphone. Keep the destination app focused — you'll paste directly into it.

2

Speak naturally

Audio is buffered in real time. Speak as you normally would — don't worry about filler words or imperfect grammar, the LLM handles that later.

3

Stop recording (or wait for silence detection)

Click "Stop Recording" or stay quiet for ~2 seconds. The icon switches to ⏳ as processing begins.

4

Whisper transcribes the audio

OpenAI Whisper (running locally via openai-whisper) converts the audio buffer to raw text. No network request leaves your machine.

5

Ollama improves the text

The raw transcription is sent to your local Ollama instance (llama3.2 by default). The LLM fixes grammar, clarifies phrasing, and removes filler — while keeping your meaning intact.

6

Polished text lands in your clipboard

A macOS notification previews the result. Hit ⌘V to paste wherever your cursor is.

Quick Start

Up and running in minutes

Three prerequisites, one command to launch.

1 — Install Ollama & pull the model

# Install Ollama via Homebrew
brew install ollama
ollama serve
ollama pull llama3.2:latest

2 — Install PortAudio & Python dependencies

# PortAudio is required by PyAudio on macOS
brew install portaudio
pip install -r requirements.txt

3 — Grant microphone permission & launch

# System Preferences → Security & Privacy → Microphone → allow Terminal
python run.py
# The Speak-Type icon appears in your menu bar — you're ready.

Prefer a different Whisper model size or LLM? Edit config.yaml — no code changes required. See the configuration docs for all options.

Privacy

Your voice. Your machine. Full stop.

Speak-Type was designed from day one to never exfiltrate any data.

✓

Local processing only
Whisper runs on-device. Ollama calls localhost:11434. No audio or text is sent to any external server.

✓

Audio buffers cleared immediately
After each transcription the audio buffer is zeroed out and released from memory.

✓

No transcription logging
Transcriptions are never written to disk by default. Toggle in config.yaml if you need debugging output.

✓

Minimal system permissions
Only microphone access is requested. No accessibility, screen recording, or network entitlements needed.

✓

Open source & auditable
Every line of code is on GitHub under the MIT licence. Read it, fork it, own it.

Data flow

🎙️ Microphone → PyAudio buffer local
📝 Audio → Whisper (on-device) local
✨ Text → Ollama (localhost) local
📋 Result → System clipboard local
🚫 External servers / cloud APIs blocked
